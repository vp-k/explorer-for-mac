# Explorer for Mac — 기능 정의서

macOS 에서 Windows 11 파일 탐색기와 같은 방식으로 동작하는 파일 관리자.
목표 사용자는 Windows 에서 넘어와 Finder 가 낯선 사람이다.
조사 근거는 `docs/research.md` 를 본다.

## 1. 기술 구성

| 항목 | 결정 |
|---|---|
| 언어/UI | Swift 6 툴체인, AppKit (NSOutlineView/NSTableView/NSCollectionView) |
| 빌드 | SwiftPM. `scripts/build-app.sh` 가 `build/Explorer.app` 번들 생성 |
| 최소 OS | macOS 14 |
| 모듈 | `ExplorerCore` (Foundation 전용, 테스트 대상) / `Explorer` (AppKit UI) |
| 테스트 | `swift test` (ExplorerCoreTests) |

## 3. 기능 목록

우선순위: P0 = 없으면 출시 불가, P1 = 이번 버전 포함, P2 = 여유 있으면.

### 3.1 탐색

| ID | 기능 | 우선 | 동작 |
|---|---|---|---|
| N1 | 뒤로/앞으로 | P0 | 버튼, Cmd+[ / Cmd+], Alt+←/→ 대응 ⌥←/⌥→, 마우스 뒤로/앞으로 버튼 |
| N2 | 위로(상위 폴더) | P0 | ↑ 버튼, ⌥↑, Backspace(목록 포커스 시) |
| N3 | 새로고침 | P0 | 버튼, F5, Cmd+R. 폴더 변경 자동 감지도 한다 |
| N4 | 주소 표시줄 경로 버튼 | P0 | 경로 조각 클릭 시 이동. 조각 옆 `>` 클릭 시 하위 폴더 메뉴 |
| N5 | 주소 직접 입력 | P0 | 빈 곳 클릭, Cmd+L, ⌥D, F4 로 편집 모드. 경로 입력 후 Enter. `~`, `\`, `%USERPROFILE%`, 따옴표 경로 허용. 없는 경로면 오류 알림 |
| N6 | 탐색 창 | P0 | 홈 / 빠른 액세스(고정 폴더) / 내 Mac(볼륨 목록, 용량 막대) / 휴지통. 폴더 트리 펼치기 |
| N7 | 빠른 액세스 고정 | P1 | 우클릭 "빠른 액세스에 고정/해제". JSON 저장 |
| N8 | 탭 | P1 | Cmd+T 새 탭, Cmd+W 닫기, Ctrl+Tab 전환, 가운데 클릭으로 폴더를 새 탭에 열기 |
| N9 | 새 창 | P1 | Cmd+N |
| N10 | 내 Mac 화면 | P1 | 홈의 표준 폴더와 드라이브 카드(용량 막대) |

### 3.2 파일 목록 보기

| ID | 기능 | 우선 | 동작 |
|---|---|---|---|
| V1 | 자세히 보기 | P0 | 열: 이름 / 수정한 날짜 / 유형 / 크기. 열 너비 조절, 머리글 클릭 정렬 |
| V2 | 폴더 우선 정렬 | P0 | 어느 정렬에서도 폴더가 먼저. 이름은 자연 정렬 |
| V3 | 아이콘 보기 | P1 | 큰 아이콘 / 보통 아이콘 / 목록. Cmd+1~4 로 전환 |
| V4 | 숨김 항목 표시 토글 | P0 | 보기 메뉴, Cmd+Shift+. |
| V5 | 확장자 표시 토글 | P1 | 기본은 항상 확장자 표시 |
| V6 | 상태 표시줄 | P0 | "N개 항목", "N개 항목 선택함 크기" |
| V7 | 미리 보기 창 | P1 | ⌥P 토글. QuickLook 미리 보기 |
| V8 | 잘라낸 항목 흐리게 | P1 | Cut 상태 항목은 반투명 |
| V9 | 타이핑으로 항목 이동 | P0 | 목록에서 글자 입력 시 해당 이름으로 선택 이동 |
| V10 | 아이콘 | P0 | 시스템 파일 아이콘(NSWorkspace) |

### 3.3 파일 작업

| ID | 기능 | 우선 | 동작 |
|---|---|---|---|
| F1 | 열기 | P0 | Enter, 더블클릭. 폴더는 들어가고 파일·앱은 기본 앱으로 연다 |
| F2 | 잘라내기/복사/붙여넣기 | P0 | Cmd+X / Cmd+C / Cmd+V. 붙여넣기 시 잘라내기면 이동. Finder 와 대지 호환 |
| F3 | 이름 바꾸기 | P0 | F2 로 인라인 편집. 확장자 제외한 부분만 선택. Enter 확정, Esc 취소 |
| F4 | 삭제 | P0 | Delete / Cmd+Backspace → 휴지통. Shift+Delete → 확인 후 영구 삭제 |
| F5 | 새 폴더 | P0 | Cmd+Shift+N. 만든 뒤 바로 이름 편집 |
| F6 | 새 파일 | P0 | 새로 만들기 메뉴 → 텍스트 문서. 만든 뒤 이름 편집 |
| F7 | 실행 취소 | P1 | Cmd+Z 로 마지막 복사/이동/이름 바꾸기/삭제/만들기 되돌림, Cmd+Shift+Z 다시 실행 |
| F8 | 충돌 처리 | P0 | 같은 이름이 있으면 "덮어쓰기 / 건너뛰기 / 둘 다 유지" 대화상자 |
| F9 | 같은 폴더에 붙여넣기 | P0 | "이름 - 복사본" 으로 복제 |
| F10 | 드래그 앤 드롭 | P1 | 같은 볼륨은 이동, 다른 볼륨은 복사, ⌥ 누르면 복사. 다른 앱과도 주고받기 |
| F11 | 압축/풀기 | P1 | "ZIP 파일로 압축", zip 우클릭 "압축 풀기" |
| F12 | 경로 복사 | P0 | 우클릭 "경로로 복사" (Cmd+Shift+C) |
| F13 | 속성 | P1 | Cmd+I / ⌥Enter. 위치, 크기(폴더 재귀), 포함 항목 수, 날짜 |
| F14 | 터미널에서 열기 | P1 | 우클릭 메뉴 |
| F15 | Finder 에서 보기 | P2 | 우클릭 메뉴 |
| F16 | 연결 프로그램 | P1 | 우클릭 "연결 프로그램" 하위 메뉴 |

### 3.4 검색과 선택

| ID | 기능 | 우선 | 동작 |
|---|---|---|---|
| S1 | 검색 상자 | P0 | Cmd+F, F3. 현재 폴더 하위 재귀 이름 검색, 결과에 "폴더" 열 표시 |
| S2 | 와일드카드 | P1 | `*.pdf`, `rep?rt` |
| S3 | 모두 선택 / 선택 반전 | P0 | Cmd+A. 선택 반전은 메뉴 |
| S4 | 다중 선택 | P0 | Shift/Cmd 클릭, 고무줄 선택 |

### 3.5 컨텍스트 메뉴

- 항목 위: 열기, 연결 프로그램, 새 탭에서 열기, 잘라내기, 복사, 경로로 복사, 이름 바꾸기, 삭제, ZIP 압축, 압축 풀기(zip), 빠른 액세스에 고정, 터미널에서 열기, Finder 에서 보기, 속성
- 빈 곳: 보기, 정렬 기준, 새로 고침, 붙여넣기, 새로 만들기(폴더/텍스트 문서), 터미널에서 열기, 속성

## 4. 단축키 원칙

macOS 관례를 지키되 Windows 키 습관도 받는다.
Ctrl 조합은 Cmd 조합과 같게 동작한다 (Ctrl+C = Cmd+C 등).

| 동작 | 키 |
|---|---|
| 열기 | Enter, Cmd+↓ |
| 상위 폴더 | Backspace, ⌥↑, Cmd+↑ |
| 뒤로/앞으로 | ⌥←/⌥→, Cmd+[ / Cmd+] |
| 이름 바꾸기 | F2 |
| 휴지통 | Delete(⌦), Cmd+Backspace |
| 영구 삭제 | Shift+Delete, Cmd+⌥+Backspace |
| 주소 표시줄 | Cmd+L, ⌥D, F4 |
| 검색 | Cmd+F, F3 |
| 새 폴더 | Cmd+Shift+N, Ctrl+Shift+N |
| 새로 고침 | F5, Cmd+R |
| 속성 | Cmd+I, ⌥Enter |
| 숨김 표시 | Cmd+Shift+. |
| 보기 전환 | Cmd+1(자세히) ~ Cmd+4(큰 아이콘) |
| 탭 | Cmd+T, Cmd+W, Ctrl+Tab |

## 5. 완료 기준 (DoD)

1. `swift build` 경고 없이 성공, `swift test` 전부 통과.
2. `scripts/build-app.sh` 로 만든 앱이 실행되고 홈 폴더를 자세히 보기로 연다.
3. 3장의 P0 전부 동작. P1 은 구현 또는 남은 일에 기록.
4. 코드 리뷰 (Claude + Codex 교차) 에서 Critical/High 없음.
5. 실제 앱을 띄워 주요 시나리오를 화면으로 확인.
