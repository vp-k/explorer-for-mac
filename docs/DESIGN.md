# 디자인 기준서

목표는 "Mac 앱의 완성도에 Windows 11 탐색기의 분위기"입니다.
Windows 를 복제하지 않습니다. Windows 사용자가 보자마자 "아, 탐색기처럼 쓰면 되겠구나" 하고 느끼면 됩니다.
조작 방식(SPEC.md)은 바꾸지 않습니다. 이 문서는 겉모습만 다룹니다.

## 1. Windows 느낌을 주는 핵심 신호

아래 다섯 가지가 "탐색기 같다"는 인상을 만듭니다. 우선순위 순서입니다.

| 신호 | 적용 방법 |
|---|---|
| 노란 폴더 | 일반 폴더 아이콘을 Windows 식 노란색 폴더로 그립니다. 패키지(.app)와 파일은 시스템 아이콘을 그대로 씁니다 |
| 제목 표시줄 안의 탭 | macOS 기본 탭 막대 대신 자체 탭 줄을 씁니다. 신호등 버튼 오른쪽에 탭이 있고 활성 탭은 아래 도구 영역과 같은 색으로 이어집니다 |
| 선택 표시 | 둥근 사각 하이라이트에 연한 강조색을 씁니다. 탐색 창은 선택 항목 왼쪽에 짧은 세로 강조 막대를 둡니다 |
| 주소 줄 배치 | ← → ↑ ⟳ 원형 버튼, 둥근 주소 상자, 오른쪽 둥근 검색 상자를 한 줄에 둡니다 |
| 명령 모음 | "새로 만들기" 강조 버튼, 아이콘 버튼 묶음, 구분선, "정렬 ▾" "보기 ▾" "···" 순서입니다 |

## 2. 색

라이트와 다크를 모두 지원합니다. 모든 색은 한 파일의 토큰으로 정의합니다.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| accent | #005FB8 | #60CDFF | 강조 버튼, 선택 막대, 포커스 테두리 |
| windowBackground | #F3F3F3 + 반투명 재질 | #202020 + 반투명 재질 | 탭 줄, 탐색 창 (Mica 느낌) |
| toolbarBackground | #F9F9F9 | #2C2C2C | 주소 줄, 명령 모음, 활성 탭 |
| contentBackground | #FFFFFF | #191919 | 파일 목록 |
| hoverFill | 검정 4% | 흰색 6% | 마우스를 올린 행, 버튼 |
| selectionFill | #CCE4F7 계열 | #0F3A5A 계열 | 선택한 행. 창이 비활성이면 회색으로 |
| secondaryText | #5D5D5D | #A0A0A0 | 날짜, 유형, 크기 열 |
| divider | 검정 8% | 흰색 8% | 영역 구분선 |
| folderYellow | #FFC83D 본체, #E8A82A 탭 | 같은 색 | 폴더 아이콘 |
| driveBar | accent. 사용률 90% 이상이면 #C42B1C | 같은 규칙 | 드라이브 용량 막대 |

## 3. 형태와 크기

| 요소 | 값 |
|---|---|
| 모서리 반경 | 버튼과 입력 상자 6, 선택 하이라이트 4, 카드 8 |
| 글꼴 | 시스템 글꼴. 본문 13, 보조 12, 상태 표시줄 11 |
| 목록 행 높이 | 28 |
| 탐색 창 행 높이 | 28, 들여쓰기 16 |
| 아이콘 크기 | 자세히 보기 16, 탐색 창 16, 큰 아이콘 64 이상 |
| 주소 줄 높이 | 32 |
| 명령 모음 높이 | 40 |
| 테두리 | 가능한 한 쓰지 않습니다. 색 차이와 구분선 하나로 영역을 나눕니다 |
| 아이콘 | SF Symbols. 명령 모음 아이콘은 계층형으로 그리고 강조색을 은은하게 섞습니다 |

## 4. 화면별 요구

- **탭 줄:** 창 맨 위에 둡니다. 탭마다 폴더 아이콘, 이름, 닫기 버튼을 넣습니다. 오른쪽 끝에 "+" 버튼을 둡니다. 탭이 하나여도 보입니다. Cmd+T, Cmd+W, Ctrl+Tab 은 계속 동작해야 합니다.
- **주소 상자:** 경로 조각 사이에 `›` 를 넣습니다. 조각에 마우스를 올리면 hoverFill 을 보입니다. 맨 앞에 현재 폴더 아이콘을 둡니다.
- **탐색 창:** 반투명 재질을 씁니다. 섹션은 홈, 빠른 액세스, 내 Mac, 휴지통 순서입니다. 빠른 액세스 항목에는 고정 핀 아이콘을 흐리게 표시합니다.
- **파일 목록:** 열 머리글은 얇게 하고 구분선만 둡니다. 날짜, 유형, 크기는 secondaryText 로 씁니다. 행에 마우스를 올리면 hoverFill 을 보입니다. 잘라낸 항목은 지금처럼 반투명하게 둡니다.
- **아이콘 보기:** 항목 카드에 hover 와 선택 하이라이트를 둡니다. 이름은 두 줄까지 보입니다.
- **내 Mac 화면:** "폴더"와 "장치 및 드라이브" 두 구역으로 나눕니다. 드라이브 카드에는 아이콘, 이름, 용량 막대, "N GB 중 M GB 사용 가능" 을 넣습니다.
- **상태 표시줄:** 높이 24, 글자 11 입니다. 오른쪽에 자세히/아이콘 전환 버튼을 둡니다.
- **빈 폴더:** "이 폴더는 비어 있습니다." 를 가운데 secondaryText 로 보입니다.

## 5. 하지 않을 것

- Windows 로고, Segoe 글꼴, Microsoft 아이콘 이미지를 쓰지 않습니다.
- 창 버튼을 오른쪽으로 옮기지 않습니다. macOS 신호등 버튼을 유지합니다.
- 리본 메뉴(Windows 10 식)는 만들지 않습니다.
